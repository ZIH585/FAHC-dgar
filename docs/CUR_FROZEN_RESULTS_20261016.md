## 路由器实际做了什么

236/236 条 query 都选择 R；训练部分和其留出部分在五个阶段也全部选择 R。
预测概率范围为 0.518074..0.994004，已经偏离初始化的 0.5 且随 query 变化。
因此结果并非“没有加载 router 而固定走旧评分”的证据；实际概率与 0.5
阈值确实产生了全 R 的决定。

* R 更优：102 条；0 更优：60 条；相同：74 条。
* 60 条 0 更优的 query 占 25.42%，其中 forward 44 条、inverse 16 条。
* 日志的加权符号准确率 macro=88.3337%，独立复算的“始终 R”常数策略也
  为 88.3337%。该指标没有展示 query 选择优于常数策略。
* 根据 |u| 权重，R 更优样本的效用权重总量明显占优。当前模型学会保持总体较强
  的路径，同时错过少数 0 更优 query 的收益。

为避免方向先验及跨阶段概率偏移造成虚假的区分能力，额外只在同一阶段、
同一方向内，对非零效用的正/负 query 配对计算概率 AUC，按配对数合并：

| 方向 | 正负配对数 | AUC |
|---|---:|---:|
| forward | 258 | 0.503876 |
| inverse | 225 | 0.500000 |

在本小样本内，当前概率对方向内部的路径优劣没有展示稳定区分能力。
这些配对并非独立样本，不把 AUC 接近 0.5 当作统计等价性或不可学习性的证明。

## 失败解释及边界

1. **决策退化。** 训练及验证均全选 R，当前特征、训练规则和 10 步拟合未能
   把互补空间兑现成非平凡路由。这是本轮直接失败点。
2. **两个路径训练条件不对称。** 源 checkpoint 只针对 mean+Shared 注入训练，
   0 是临时关闭注入的干预，没有经过正式 CUR 的无注入 entity loss 训练。
   始终 0 的 macro 比 R 低 16.2086 pp，是强烈的路径差异；这会让 |u| 加权
   拟合偏向保留 R。它限制诊断结论，不能证明双路径训练后仍有相同差距。
3. **当前可观测特征的 query 级信号尚未得到支持。** 熵、margin、重合率、
   支持度和关系/方向提供的信息在这批 query 上没有体现方向内有效排序。
   不能仅凭总体 88% 的加权准确率认定模型学会了识别有效回放。

此前“另行训练的 Original forward + mean+Shared inverse”的比较，与
“同一 mean+Shared checkpoint 的 forward 关闭注入”是两个不同操作。
本轮固定方向策略下降不能反向推翻前者，也不能直接把前者的收益迁移为后者。

本轮没有证明所有效用路由都无效，也没有正式训练 CUR 后的最终 TEST 性能。
按预设研发门槛，现有证据不足以投入三组完整实验；不在 VALIDATION 上扫描
阈值再把事后最优阈值作为方法收益。
