# FAHC-DGAR 完整复查记录

日期：2026-10-06。实现版本：`full-hcp-v2`。

## 复查范围

检查候选历史索引、HCP 加载、遗忘风险、覆盖贪心、事实限额、探测恢复、
正式训练接口、KD、验证、早停、检查点、最终评估及命令行配置。
复查期间没有执行数据集训练，没有调用真实优化器更新，没有使用 GPU。

## 本次确认并修复的问题

| 问题 | 修复 |
| --- | --- |
| 默认参数下每个候选仅用约 3 个事实打分，改变了完整 HCP 风险和覆盖目标 | 对完整候选计算风险与覆盖；选择时间片后统一随机限额回放 |
| 小事实预算与完整 HCP 打分不兼容 | 种子控制的时间片内打乱、片间轮转，去重后最多回放 B 个事实 |
| 贪心同分时固定偏向最早快照 | 用独立、可复现的随机数对象处理同分 |
| 探测使用新 Adam，与正式更新的动量不同 | 独立复制主 Adam 的动量和参数组，仅覆盖探测学习率 |
| 探测恢复未覆盖混合子模块模式、旧梯度和临时缓存 | 保存并在 `finally` 恢复；增加异常和人为状态损坏的恢复检查 |
| 加载最佳权重后仍保留末轮 Adam 动量 | RGCN 与扩散分别恢复对应最佳轮次的优化器状态 |
| 每轮验证重新随机抽 HCP 和噪声，影响早停及训练随机流 | 阶段内固定验证特征；验证与最终评估隔离随机状态 |
| 空 HCP 最终评估可能引用未初始化或上轮遗留的图 | 每片明确设置为 None；空三元组采用 long 类型和 `(0, 3)` 形状 |
| 测试历史窗口混用了训练窗口长度 | 根据测试窗口独立截取，并限制起点至少为 0 |
| 默认自环路径强制 CUDA | 两套 RGCN 自环均跟随输入设备 |
| 非归一化静态图零向量造成 NaN 梯度 | 限制分母并排除零范数实体的静态约束 |
| `Linear` 训练融合与预测融合不同 | 预测使用同样的 `args.diffuc` |
| 提前停止或关闭扩散时可能加载不存在的扩散检查点 | 活跃扩散按阶段训练并存档；关闭时跳过扩散检查点 |
| 多次遍历时间序列会把末尾知识带回早期阶段 | FAHC 和遗忘诊断要求单次按时间遍历 |
| `mu` 接收字符串、False 字符串被当作 True、部分非法参数晚报错 | 数值/布尔解析和训练前配置校验独立为模块 |
| 检查点哈希遗漏学习率、模型宽度和 replay 权重等参数 | v2 签名包含完整训练/模型设置；排除报告和运行位置参数 |
| 原 DGAR 没有同口径历史诊断 | 增加 `--fahc-diagnostics`；日志附配置、运行 ID、实际事实数、覆盖数和 KD 门控数 |

## 结论的范围

本次没有在真实数据集上运行探测更新或训练，不能据此证明 MRR 提升、
遗忘降低、实际耗时或 GPU 上完整训练通过。

风险与 KD 使用当前阶段历史图上的实体预测代理，不注入扩散特征。
主损失继承 DGAR：实体 replay 有不乘 `mu` 的 CE 项，因此 `mu=0` 不会关闭全部回放。
B 是唯一 HCP 事实的上限，重复或不足会使实际数量小于 B；相同上限不保证实际数量相同。
总历史存储仍使用原缓存，不是固定字节的在线记忆。

原数据协议仍为合并时间片后逐片 80/10/10 留出，过滤答案来自对应评估划分。
历史缓存可能包含仅正向事实，也可能包含正向和逆向事实；实验应使用一致缓存。
上述口径和限制已同步写入 README。
