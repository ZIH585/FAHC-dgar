# ICEWS14s：六组正式实验与 random+KD 的最终汇总

日期：2026-10-11。分析开始时 Git HEAD：`6d82d5e`。
本次只读取已有日志、CSV和代码，执行标准库统计并归档；未启动训练、
模型评估或 GPU 任务，未修改训练代码。

## 1. 本轮结论

random+KD（lambda0.03、T2、教师置信阈值0.5）相对 random 在完整推理历史
指标上有小幅数值收益：验证历史 MRR +0.4285、测试历史 MRR +0.4406 个百分点。
与此同时，最新 Current 的验证/测试 MRR 分别下降8.8457/2.5380个百分点。
所以不能说KD完全没有收益；准确结论是历史收益伴随最新快照代价，未通过
此前固定的综合筛选门槛。

此前 risk、coverage、risk+coverage 三组选择器均未超过 random 的主历史
指标，机制检查也仅1/3阶段通过。独立KD的历史收益不能作为风险选择有效的
证据。结束本版选择器与这组KD配置的调参，转向新的主模块；保留KD实现和
本次正负结果，作为后续辅助机制候选。它既不是已确认的稳定改进，也不是
所有KD或遗忘感知方法无效的证明。

空机制阶段不会触发诊断。original仍使用不限额随机HCP路径，CLI的B不对它
执行裁剪。表中使用同批次v3结果，不混入旧modify日志的分数。

| 指标 | random | random+KD | 差值（百分点） |

| 验证查询汇总MRR | 49.4386 | 49.7996 | +0.3610 |

| 测试历史Hits@10 | 70.7197 | 70.9372 | +0.2175 |

此前在KD启动前固定的工程筛选标准：历史完整验证MRR至少比random高0.5
个百分点，Current完整验证MRR下降不超过1个百分点。

| 判据 | 要求 | 实际 | 是否通过 |
| --- | ---: | ---: | --- |
| 验证历史MRR | >=50.6924% | 50.6209% | 否，距门槛0.0715个百分点 |
| 验证Current MRR | >=70.3330% | 62.4873% | 否，距门槛7.8457个百分点 |

0.5个百分点不是统计显著性标准；历史收益略低于它不能被写成完全没有收益。
但两个条件都未通过，不在看到结果后降低门槛来选中该配置。

当前最后快照测试只有18条事实，逆关系扩展后36个查询；Current对少量
预测变化敏感，不能从一次结果确认普遍的稳定性/可塑性下降。验证和测试均
呈Current下降，当前保留标准仍未满足。

## 6. 门控、事实预算与历史模式诊断

### 6.1 KD门控

CSV的`KD_active_fraction_median=0.07158`，即各阶段通过“教师正确且
置信度>=0.5”门控的回放事实比例中位数为7.158%。不是全零门控，也不是
所有回放事实的加权总比例。KD统计只在有教师的适用阶段记录。

本工作区仍没有原始`stages.jsonl`、config和status，stdout与汇总CSV也没有
逐阶段`kd_mean_loss`。因此不能独立确认每阶段非零KD损失、梯度强度或
源码/数据/缓存指纹。7.158%不能证明覆盖比例已经最优，也不是立即降低
置信阈值或增加lambda的依据。

历史指标上升、Current下降与蒸馏约束旧预测分布的权衡相符，但这只是解释
假设；小样本Current、训练轨迹及运行条件也可能影响数值，尚未查明唯一原因。

以下为百分数，与完整diffusion推理的主表分开解释。

max-over-stage遗忘。当前没有原始阶段JSONL，数值来自CSV并未独立重算。

## 7. 归档与后续行动

本地结果。MRR/Hits保存为0..1小数；无论文验证/诊断数据的字段留空，不造数。
新日志和用户原始汇总CSV一起存入Git。此前报告保留为各阶段的历史记录。

不追加risk+coverage+KD来掩盖选择器没有显示收益的事实，也不扩展lambda、
置信阈值或温度网格。下一步优先设计新的主模块和明确的机制假设；KD可
保留为辅助候选，在主模块有独立证据后再决定是否使用。本轮结论不是所有
KD参数无效，也不承诺换模块一定提升。
