## 回放量差异

本次 FAHC 的逐阶段日志为
`logs/fahc_ICEWS14s_risk+coverage_1_20261006_170930_107420_1034aefb09.jsonl`。
共有 364 个阶段记录，363 个阶段含 HCP 选择。
按日志中的真实选中索引，从现有缓存重建完整去重 HCP 联集：

| 项目 | 数值 |
| --- | ---: |
| 完整选中 HCP 唯一事实数中位数 | 1895 |
| 完整选中 HCP 唯一事实数范围 | 40–2603 |
| 实际回放事实数中位数 | 128 |
| 每阶段保留比例的中位数 | 6.75% |
| 被 B=128 裁剪的阶段 | 360 / 363 |
| 选中完整 HCP 的关系覆盖中位数 | 121 |
| 实际回放的关系覆盖中位数 | 38 |

原 DGAR 正常 HCP 路径没有 128 事实限额；`reply_batch_num=128` 不代表
其正常随机 HCP 路径也使用该限额。因此，本次相对 original 的差距同时
包含选择方法与回放量改变，不能直接归因于风险选择失败。
把 128 推荐为与不限额 original 的直接对比配置是不严谨的。

风险和覆盖基于完整 HCP；预算裁剪会丢掉其中大部分事实，降低最终 replay
与所优化目标的对应程度。训练使用 128 事实，但最终测试仍沿用原 DGAR
的不限额历史特征路径；这也形成输入规模差异。
这些是代码与日志确认的差异，尚不能证明各自造成了多少 MRR 损失。

## 覆盖项权重

在阶段 70–364，风险项占选中贪心总增益的中位数约 14.10%；
平均单个选中 HCP 的风险增益中位数为 0.02099，已乘 eta 的覆盖增益
中位数为 0.12668。因此 eta=1 在本次训练轨迹中更偏向覆盖。

在固定已保存风险分数下重做选择，阶段 100/200/300/364 的 eta=1 选择
与纯风险选择分别重合 18/19/19/17 个时间片；eta=0.1 时分别重合
30/30/28/27 个。这只是离线选择对比，不能当作降低 eta 后的训练效果。

## 下一步实验顺序

先保留 seed=1、k=35、KD=0 和其他设置，仅改变必要变量：

1. `random, B=128`：与已有 `risk+coverage, B=128` 比较，隔离选择差异。
2. `random, B=4096`：与步骤 1 比较，检查强裁剪带来的损失。
3. `risk+coverage, B=4096, eta=1`：与步骤 2 比较，检查宽松限额下的选择效果。

4096 大于本次选中 HCP 联集的最大值 2603，仅作为消除强裁剪的诊断。
重跑后选择和事实数可能改变，应检查新日志，不能宣称所有运行均完全不限额。
宽松限额下不同方法的实际事实数可能不同；正式固定事实预算实验还应使用
共同的较小限额，并报告实际事实数。

如果步骤 3 仍弱于步骤 2，再单独改变 eta 为 0.1；随后做纯风险消融。
先不要同时加入 KD、修改学习率或修改实体覆盖权重，否则难以定位原因。
也不能承诺加大预算或降低 eta 一定提高 MRR。

主流程现增加完整事实数、裁剪保留比例、风险与覆盖增益组成的日志字段，
方便后续直接判断上述差异。该改动不改变选择、损失或优化步骤。
