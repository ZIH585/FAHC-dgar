# ECRI 最终评估与停止决定（2026-10-12）

**决定：结束当前 ECRI 设计的继续调参和完整重训，保存为负实验。**
实体预测的完整 TEST/VALIDATION 没有提升，固定 checkpoint 诊断也没有达到
事先定义的继续条件：演化门控未优于仅偏置或打乱信号。保留“融合比例有校准空间”
这一线索；固定 alpha=0.75 的小样本收益不是已超过 Original 的正式结果。

## 1. 完整训练结果

| 指标 | Original | ECRI | ECRI−Original |
|---|---:|---:|---:|
| TEST pooled MRR | 0.494907 | 0.490509 | -0.004398 |
| TEST Hits@1 | 0.385782 | 0.382694 | -0.003088 |
| TEST Hits@3 | 0.556892 | 0.550715 | -0.006177 |
| TEST Hits@10 | 0.697822 | 0.695655 | -0.002167 |
| TEST past macro MRR | 0.499344 | 0.494876 | -0.004468 |
| VALIDATION pooled MRR | 0.491407 | 0.489153 | -0.002254 |
| VALIDATION past macro MRR | 0.499225 | 0.497548 | -0.001677 |

ECRI 的关系预测有所提升，未转化成主要实体 forecasting 指标的收益。Current
TEST 上升而 Current VALIDATION 下降，末片只有 36 个含逆 query 的样本，不能用
它抵消全局结论。训练墙钟多约 12.6%。完整 raw/filtered 指标见首次 metrics.csv。

## 2. 新诊断完整且匹配原训练运行

输入为 `ecri-gate-diagnostic-20261012_131956/summary.json`、`queries.csv` 与同名日志。
阶段 90/180/300，各 16 条正向事实，含逆向后共 96 个 query、48 对事实。
CSV 的 query 唯一性、逆方向实体交换和关系 +230、全部 MRR/Hits 均独立重算通过。

- 运行源码哈希与训练配置相同，没有使用 source mismatch override；数据与缓存
  哈希也一致，checkpoint gate 与末条阶段记录匹配。
- 三片 HCP 分别为 322、200、413 条，均非空；同一模型、历史图、query、过滤答案
  和生成表示用于每个片内所有模式，回放仅生成一次。
- 打乱对照确实改变了约 91.7%～98.6% 的可信实体演化特征，并非没有发生打乱。
- 没有参数梯度、optimizer 更新或 checkpoint 写入；日志完整结束。

前次本地源码哈希差异现在可以定位：诊断提供的逐文件列表中，仅 src/main.py 与
本地不同；模型、ECRI、decoder、diffusion 等文件均相同。诊断在训练服务器上与
实际训练源码相匹配，不影响本次对照的内部可比性。未收到服务器 main.py 全文，
不推断差异的具体性质；后续仍应记录实际训练版本。

## 3. 固定 checkpoint 的 VALIDATION 诊断

以下只比较同一个 **ECRI 训练后的 checkpoint**，不是分别重训的模型。

| 模式 | MRR | Hits@1 | Hits@3 | Hits@10 |
|---|---:|---:|---:|---:|
| full ECRI | 0.506782 | 0.406250 | 0.552083 | 0.708333 |
| bias_only：去掉 d/u，保留 bias/c | 0.507891 | 0.406250 | 0.552083 | 0.708333 |
| scalar_alpha：同 checkpoint 的标量系数 | 0.507912 | 0.416667 | 0.541667 | 0.697917 |
| shuffle：5 次均值 | 0.508700 | 0.408333 | 0.554167 | 0.710417 |
| 固定 alpha=0.25 | 0.372939 | 0.281250 | 0.416667 | 0.572917 |
| 固定 alpha=0.75 | **0.524092** | **0.427083** | **0.562500** | **0.718750** |
| current_only：alpha=1 | 0.384306 | 0.270833 | 0.416667 | 0.645833 |

shuffle 的五次 pooled MRR 均高于 full，范围 0.507144～0.513677。
五次是同模型下的随机打乱，不是五个模型 seed。scalar_alpha 也不是单独训练的
Original；0.524092 不能和 Original 全 TEST 的 0.494907 横向比较。

### 演化项没有显示独立正收益

full−bias_only 的 MRR 为 -0.001109；96 个 query 中 80 个排名相同，6 个变好，
10 个变差。三个阶段的差值依次为 +0.000083、-0.000177、-0.003233，没有一致
正向作用。Hits@1/3/10 的总体值完全相同，其中 Hits@3 有一升一降相互抵消。

高演化组 full−bias_only 的平均 RR 差值为 -0.007781，低演化组为 +0.002782。
高组负差主要由阶段 300 的同一条正/逆事实对驱动；去掉该对后为 -0.000487。
这是对主创新缺少积极支持，不能解释为高演化一定有害。

两组 alpha075−alpha025 均为正，高组 +0.151890、低组 +0.111019。这个方向性
观察符合“更多当前表示可能有益”的一部分假设，但固定比例同样受益，且没有让
正确匹配的演化 gate 优于 bias/shuffle；尚不足以支持该条件变量的实际辨别价值。

### 融合仍重要，比例有校准线索

alpha=0.75 在三个预选片的 MRR 都好于 full，差值分别为 +0.017929、+0.011490、
+0.022511，pooled 为 +0.017310。但它仍是 48 个正向事实上的探索性观察，
不能直接设为所有数据集、时间片和 seed 的最佳比例。

只用当前表示的 MRR 为 0.384306，三个片都下降；偏历史过多的 alpha=0.25 也明显
下降。生成历史表示对这个已训练模型的推理有功能作用，合适的混合比可能比新的
演化变量更值得校准。current_only 没有移除已经通过回放学进参数的知识，不能
等同于从零训练的无回放 DGAR，也不能证明所有旧事件在所有时期都有益。

## 4. 门控的实际方向现在能说明了

ECRI checkpoint 的标量 alpha0=0.928480。47 个同时可信且命中 HCP 的 query 主体
上，完整门控的平均融合系数约 0.847059，仅偏置约 0.827903。对于这些直接融合的
主体，门控比自身原标量增加了历史混合；演化项再把系数提升约 0.019156。
这里没有单独训练的 Original alpha，不能混淆两个模型的标量。

此前仅凭 bias=1.279 无法判断实际历史权重方向；现在有 alpha0 后可以判断该
checkpoint 内的方向。实际系数还受 c、HCP 命中与时间门控影响，不把平均系数
当作最终预测中固定的当前/历史贡献百分比。

## 5. 证据边界与项目决定

为避免把逆 query 当独立数据，补做条件 bootstrap：在三个固定片内，按正/逆
事实对联合重采样 10,000 次。full−bias_only 的探索性 95% 区间约为
[-0.00583,0.00243]，alpha075−full 约为 [-0.01296,0.04387]，均覆盖 0。
这个区间条件于所选片、query、噪声与已训练模型，未包含模型 seed 方差或共享
实体事实间依赖，不作为正式论文统计检验。

因此决定依据是**没有达到预设的继续开发条件**，不是声称演化项已被统计证明
显著有害。冻结推理干预也不能排除演化信号在训练阶段曾影响参数；单独重训
ablation 才能回答那个问题。结合完整主指标已经下降，本项目当前无需继续投入
那组重训来保留此设计。

接下来执行的资源决定：

1. 封存当前 ECRI 的实现、完整结果和机制诊断；不再扫 window/kappa/采样上限，
   不叠加 KD，不为预热 weight decay 单独追加一次 ECRI 完整训练。
2. 将 alpha=0.75 保留为后续融合校准的候选对照，先确认完整验证集表现，不能称为
   新方法或已经超过 Original。未来需要研究的是生成表示的融合效用/尺度校准，
   不再默认过去结构变化必然能预测回放价值。
3. 本次不启动下一版实现，不把一轮负结果自动转化为另一个新增模块。

最终结论适用于当前 ECRI 实现和已有实验。当前方案未改善实体预测，主创新缺少
独立功能收益，停止继续开发是合理的项目选择。

结果文件：diagnostic_comparison.csv 为所有模式指标；diagnostic_audit.json 为
输入哈希、配对变化、bootstrap范围、门控系数和检查记录。全部分析只读已有结果，
没有重新评估真实模型、训练或使用 GPU。
